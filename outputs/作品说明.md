# 算法学习教练：作品说明

## 一、作品名称

算法学习教练（Algorithm Study Coach）

## 二、一句话介绍

一款面向牛客 C++ 刷题用户的 AI 学习工具，用你的真实刷题记录诊断薄弱知识点，并给出题目推荐、中文讲解、渐进提示和多解 C++ 代码。

## 三、解决什么问题

很多同学刷题是“凭感觉”做题：做过的题没有沉淀，错过的知识点反复踩坑，也不知道下一步该练什么。本作品把散落的刷题行为变成可量化、可回顾、可指导的闭环：

- 记录散落在平台上的提交结果。
- 诊断你真正薄弱的算法与数据结构方向。
- 推荐下一步该补的题。
- 对单道题提供由大模型生成的中文讲解、分步提示和多解代码。

## 四、核心功能

1. 浏览器插件记录：在牛客题目页完成提交后，插件自动抓取题目信息和提交结果，发送到本地后端。
2. 知识点画像：按数组、字符串、哈希表、动态规划、图论等知识点统计掌握度，并随时间衰减、按难度加权。
3. 薄弱点诊断：掌握度最低且练过的知识点会被标记为薄弱点。
4. 智能推荐：优先推荐薄弱知识点下未完成的题目。
5. 单题教练：对任意题目生成中文讲解、三层渐进提示和两种以上 C++ 解法。
6. 演示数据导入：没有历史记录时，也能一键导入样本数据跑完整链路。

## 五、技术架构

- 浏览器插件：Chrome/Edge Manifest V3、TypeScript、esbuild。
- 后端：Python、FastAPI、SQLAlchemy、SQLite。
- 大模型：OpenAI 兼容接口，本作品接入 DeepSeek。
- 前端：React、Vite、Tailwind、Recharts、lucide-react。
- 运行方式：全本地运行，不依赖云端数据库。

## 六、技术亮点

- 通过浏览器插件打通“刷题平台到个人学习系统”的数据链路。
- 掌握度不是简单通过率，而是综合难度权重、错误次数和时间衰减。
- 大模型生成结果写入缓存，降低重复调用成本。
- 插件只提交解析后的结构化数据，不读取或外传平台账号 Cookie。

## 七、创新点

把通用的“AI 讲题”升级成“AI 教练”：不是只解释一道题，而是从用户历史中判断该学什么，再决定讲什么、练什么，形成个性化学习闭环。

## 八、使用方式

1. 启动本地后端和看板。
2. 在 Chrome/Edge 中加载插件目录 `extension/dist`。
3. 在牛客做题，或先在看板导入演示数据。
4. 看板会展示掌握度、薄弱点和推荐题目。

## 九、后续规划

- 支持 LeetCode 等更多平台。
- 接入更多编程语言。
- 增加在线评测和代码执行反馈。
- 提供更细粒度的知识点依赖关系与学习路径。
